# AutoGrade - Code Submission & Evaluation Platform
A web-based platform that automates the submission and evaluation 
of Python programming assignments for university CS courses.

## Features
- Student code submission portal
- Automated grading via Docker sandboxing
- Test case execution against submitted code
- Structured feedback generation
- Assignment & user management

## Tech Stack
- Python / Django 5.2
- PostgreSQL
- Docker (sandboxed code execution)
- Tailwind CSS
